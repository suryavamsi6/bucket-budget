## 2026-05-13 - [Accessibility] Requirements for interactive elements
**Learning:** This application extensively utilizes icon-only variants (`variant="ghost" size="icon"`) and custom FAB (Floating Action Button) layouts. These interactive elements natively lack semantic descriptors, making them invisible or ambiguous to screen reader users. Specifically, stateful sidebar toggles lacked `aria-expanded` attributes, and quick-action buttons with global keyboard shortcuts lacked `aria-keyshortcuts`.
**Action:** When working with the standard `Button` components or M3 custom FAB definitions in this repo: 1) Always attach explicit `aria-label` attributes to icon-only buttons. 2) Ensure any toggle-style interactive element maintains synchronization with its underlying state via `aria-expanded`. 3) Make global shortcut bindings explicit to assistive tech by adding `aria-keyshortcuts="Control+N"` (or equivalent) properties where appropriate.
